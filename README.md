# Cevaplar Kitabı — Özel SVG Sürümü

Her rastgele cevap için cevap indeksine bağlı SVG illüstrasyonu oluşturulur. SVG motifleri dönüş, yıldız kümeleri, çerçeve ve farklı geometrik temaların kombinasyonlarıyla her cevapta farklı kompozisyon verir. Tek dosyalı HTML, GitHub Pages ile yayınlanabilir.

## Yayınlama
1. `index.html` dosyasını GitHub repository köküne yükleyin.
2. Settings → Pages → Deploy from a branch → main → root seçin.
3. Kaydedip yayın URL'sini bekleyin.

Plus kilidi prototip olarak görsel çalışır; gerçek kullanıcı/ödeme doğrulaması içermez.


### Özgün SVG illüstrasyonlar
Her cevap metni semantik anahtar kelimelerle eşleştirilir ve sayfada tema ile ilişkili özel vektör sahne (kapı, kum saati, filiz, kalp, göz, kuş, çiçek, anahtar, köprü, dağ, fener, denge, dalga, pusula, kilit, kitap, bulut, saat, el, güneş vb.) çizilir. SVG çizimleri ölçeklenebilir ve internet bağlantısı gerektirmez.
